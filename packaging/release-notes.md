猫咪老师桌宠 Windows x64 制作阶段更新 v0.5.6。

- 新增互动菜单：今日运势、今天吃什么、自己写签、猜拳、猜数字、抛硬币和掷骰子；结果直接由老师的限时气泡展示。
- 食物与自定义抽签列表自动保存，更新程序保留个人候选项。
- 修复文字与图片气泡方向；捕获兼容模式下优先放在老师上方，并保持角色位置不变。
- Windows 自启改用当前用户启动文件夹及原生 Unicode 快捷方式接口，适配中文路径、新用户环境及安装目录搬移后的失效入口修复，不依赖 PowerShell 创建自启入口。
- 改善 Codex CLI 的发现方式，桌面应用更新或启动环境缺少 PATH 时仍可尝试查找本机 CLI。
- 补齐点击音效、点击自言自语和旋转反馈；动作间隔在完整动作结束后生效。
- 修复独立进程多开与通用 Agent 动作衔接；更新检查和项目页指向本仓库。
- Windows 与 Ubuntu 源码已统一到 main；本 Release 的安装附件为 Windows x64。

## 已知限制

- Codex“对话中”提示存在偶发未显示的反馈，仍需持续排查；本版不宣称彻底解决。
- 猫咪老师没有唱歌素材，“音乐自动唱歌”暂不可用。
- Ubuntu 原生桌面效果仍需按 Ubuntu 指南实机验收；自动化检查不替代桌面验收。

## 下载与更新

- 在线安装器首次运行时从本 Release 下载完整程序包，并在安装前校验 SHA-256。
- 离线包包含相同版本的桌宠、动画素材和嵌入式 Python，无需目标电脑预装 Python。
- 安装范围为当前 Windows 用户；不会修改系统 PATH，也不申请管理员权限。
- Codex Hook 需要用户在 Codex 中自行审核并信任。

已有安装可运行新版 Setup.cmd 更新，个人设置和日志沿用原数据目录。
在线引导包很小，但首次运行仍需下载完整内容；离线包已经包含全部运行文件。
精确体积见 SIZE_REPORT.md，校验值见 SHA256SUMS.txt。
