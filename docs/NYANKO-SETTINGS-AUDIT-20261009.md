# 猫咪老师通用设置接入核对

本轮对角色适配与原版设置的实际调用做源码核对，只补接不需要新增角色素材的点击反馈。
不增加新设置、不改默认开关，也不重新制作角色动画。

| 功能 | 结果 |
| --- | --- |
| 普通点击音效 | 已补接原版延迟播放路径，遵守启用和音量设置；按下／松开音效包继续由继承的鼠标事件处理，避免重复播放 |
| 点击自言自语 | 已补接开关和现有台词／图片气泡，不改变候选内容或默认状态 |
| 点击黄金回旋 | 已补接；普通模式等本次点击动画结束再转，直连模式直接转，多次点击累计圈数 |
| 鼠标穿透 | 由原版窗口配置更新继承，猫咪老师未覆盖相关处理；这是源码核对，本轮未做穿透实机操作验收 |
| 自动自言自语与气泡方案 | 原版计时器与气泡样式已继承；游戏结果使用独立限时气泡，与设置中的自言自语计时分开 |
| 禁止移动与锁定位置 | 角色慢走与小跑显式检查这两个状态，并检查拖拽、抛掷与菜单打开状态 |
| 动作等待间隔 | 仍需专项适配：角色使用自己的日常编排，覆盖原版结束动作的间隔路径，本轮不强行改变动作衔接 |
| 音乐自动唱歌 | 未接：原版请求唱歌动作，猫咪老师当前动作包与公开动作列表没有该动作；需要先制作并审核素材 |
| 通用 Agent 动作表演 | 仍需角色映射：原版联动默认动作名如“写代码”“吃Token”不在猫咪老师公开动作池内；现有 Codex 状态与额度联动独立保留 |

点击回归先复现缺失，再验证音效与自言自语开关、拖拽后不误触、真实旋转控制器的
普通／直连模式、乱序结束事件及猫咪老师点击／待机编排。
声音调用在测试中静音，实际听感与 Ubuntu 桌面观感仍需实机验收。

互动列表另行修复：用户提供的 36 个食物与 5 个活动选项已写入源码的 `FOODS` /
`DRAW_OPTIONS`。保存到用户 `games.json` 后，后续编辑自动持久化；用户数据优先于源码
默认值，更新程序不覆盖已保存的列表。本轮没有自动把未来每次编辑回写 Git 工作区。

本地验证：主套件 1606 通过、8 跳过；隔离 WebM 生命周期／循环／低优先级预热分别
37／34／27 通过；打包与游戏测试 27 通过；Ruff 与差异格式检查通过。
实际 Qt 编辑器核对 36／5 条选项并检查自动保存提示，安装目录模块与源码内容一致。
本轮只更新本地源码与运行版，未推送或发布 Release。
